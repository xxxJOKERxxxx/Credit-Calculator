# Кредитный Калькулятор

**Проект для портфолио** — консольное Java-приложение для расчёта графика платежей по кредиту.

## Возможности

- Поддержка **аннуитетного** и **дифференцированного** платежа
- Учёт **первоначального взноса**
- Надёжная **валидация ввода** (защита от некорректных данных)
- Расчёт **суммы переплат** по кредиту
- Чистая архитектура с использованием **OOP** (интерфейсы, полиморфизм)

- Улучшена структура кода и читаемость

## Как запустить

1. Открой проект в **IntelliJ IDEA**
2. Запусти класс `Main.java`
3. Следуй инструкциям в консоли
